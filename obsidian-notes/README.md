# Buskr — NVIDIA Spark Hack Toronto 🎸

This repository is an **Obsidian vault** for the **Buskr** project: a GPU-accelerated, multi-agent copilot that helps street buskers in Toronto find *where to legally play, when, and what they'll earn*.

Open the folder as a vault in [Obsidian](https://obsidian.md), or just read the Markdown. Start at **[Home.md](Home.md)**.

## Structure
- `Idea/` — the concept and the multi-agent architecture
- `UX/` — form-factor decision and end-user mockups
- `Tech/` — the NVIDIA stack mapping
- `Planning/` — open decisions and hackathon logistics

Built at the NVIDIA Spark Hack - Toronto, May 29–31, 2026.
